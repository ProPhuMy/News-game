# Onboarding UI implementation plan (Claude)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** First-time players understand their next action before each stage advances. The intro becomes an illustrated three-step mini-comic with an "I'm ready" button, each phase panel says what to do now, and the full rules stay one click away.

**Architecture:** UI and copy only, in Claude paths: `src/client/ui/`, `src/client/styles/`, `src/client/visuals/palette.ts` and `tests/ui/`, plus the user-approved rewrite of `src/content/rule-cards.ts`. Timers and the ready gate are unchanged here; the intro backstop is a separate contract request awaiting the user's approval. The illustrations are hand-drawn React SVG components with colors from the palette, no image files and no text inside the art.

**Spec:** `docs/onboarding/proposal.md`. Approved visuals and captions: `.superpowers/shots/onboarding/preview-*.png`, generated by `gen.py` beside them (user approval 2026-10-26: "yes all good, one step at a time on phones").

## Global constraints

- **Copy:** captions exactly as approved. Card titles are at most 40 characters and bodies at most 240 (`ContentSchema.ruleCards`, exactly three).
- **Colors:** every illustration color comes from `palette.ts`. Add `illustration: { skin }` to each palette; it is the only new color.
- **Accessibility:**
  - Art is decorative (`aria-hidden`); captions carry the meaning.
  - Every control is reachable by keyboard.
  - Reduced motion gets no transitions.
  - The dialog uses native `<dialog>`, with Esc and focus return.
- **Untrusted text:** none of this renders user text. Existing text-only rules stay.
- **No phase clock:** timers still show the server deadline, and "How to play" never pauses the game.

## Review focus

1. **Phone stepper:** one step at a time at 640 px or narrower, with Back and Next. "I'm ready" is always available, so returning players can skip straight to it. Desktop shows all three steps.
2. **After "I'm ready":** the panel shows "Waiting for the other editors…" from the existing private `acted` flag. If the intro advances meanwhile, nothing breaks.
3. **No overflow:** no horizontal overflow and no unreachable controls at 390×844, 844×390 or 1280×720, including with stress text.
4. **Rules dialog:** works in every phase, including the no-WebGL fallback, and doesn't steal focus from a panel being typed in (the Write textarea).
5. **Round-1 hints:** show in round 1 only and never reappear later.
