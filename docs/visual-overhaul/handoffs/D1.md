### Interfaces and ownership

- `createMaterialKit(palette)` implements the agreed MaterialKit and adds `dispose`. Converted materials retain source base-color map, color, alpha/side/vertex-color settings, useful emissive/normal/bump/AO/displacement data and depth settings. MeshStandardMaterial and its MeshPhysicalMaterial subclass are supported; other classes throw an Error naming their type. AssetSource retains source-material/map ownership.
- `createAssetSource()` caches only local `/models/` GLB/glTF URLs. Each caller gets an independent rig; geometry/textures/source materials remain cache-owned. Returned Group.animations carries the imported clips through the existing interface. Caller owns cloned skeletons/mixers. Load failures propagate; a later explicit call may retry.
- `createSampleCharacter(ctx, {modelUrl,height,paper})` exposes `object`, `setPose`, `setPaper`, `dispose`. Required idle/walk/sprint clips and head/arm bones must exist. `run` maps to sprint; no nonexistent cheer/read clip is claimed.
- `createRenderingSample({container,renderer,palette,variant,view,reducedMotion?})` exposes `whenReady`, `setTime`, `dispose`. Await all characters/pieces; degraded pieces remain explicit. `setTime` validates nonnegative finite time and renders one frame synchronously. It has no RAF loop, gameplay routes or server deadline.
- Harness owns renderer/canvas. Sample configures tone mapping, color space and shadows, but never disposes renderer or removes canvas. Model loading, rig poses and teardown are covered by tests including delayed completion.
- Static edge outlines avoid the C2 open-leaf black blob. Small polygon depth offset fixes observed edge flicker; final replacement captures still need shared-tool confirmation. Skinned silhouettes use the same bones and bind matrix, with native-space normal expansion.
