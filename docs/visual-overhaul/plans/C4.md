## Task 1 — Sign clipped under the roof eave (bank and town hall)

C3 deferred minor, confirmed in `baseline/bank.png` and `baseline/town_hall.png`: the roof overhang hides the top of the `BANK` and `TOWN HALL` signs. Cause: the sign sits near the wall top, and the roof slab reaches past the wall front, so the eave cuts the sightline.

Geometry today:
- Bank: wall top 6, wall front 1.9, roof depth 5 (eave front z 2.5), sign center y 5.4, height 0.7, door top 4.8.
- Town hall: wall top 5.4, wall front 2.1, roof depth 4.9 (eave front z 2.45), sign center y 5.0, height 0.45, door top 4.7.

**Files:** `bank.ts`, `town-hall.ts`, `tests/town/architecture/civic.test.ts`.

- [ ] **Step 1: Write the failing test** in the existing `describe.each(cases)` block of `civic.test.ts`:

```ts
it.each([45, 55])('sign is not hidden by the eave at camera pitch %i°', (pitch) => {
  const root = create(fakeContext()).root;
  root.updateMatrixWorld(true);
  const signBox = new THREE.Box3().setFromObject(root.getObjectByName(sign)!);
  const roofBox = new THREE.Box3().setFromObject(root.getObjectByName(roof)!);
  const eaveY = roofBox.min.y;
  const eaveZ = roofBox.max.z;
  const slope = Math.tan((pitch * Math.PI) / 180);
  // The ray from the sign's top front edge toward the camera passes below the eave.
  expect(signBox.max.y + (eaveZ - signBox.max.z) * slope).toBeLessThanOrEqual(eaveY);
});
```

Add a `roof` field to `Case` (`bank-roof`, `town-hall-roof`, `clinic-roof`) and name each roof slab mesh to match. The clinic case is expected to pass; if it fails, fix it the same way.

- [ ] **Step 2: Run it.** `npm run test -- tests/town/architecture/civic.test.ts`. Expected: bank and town hall FAIL.
- [ ] **Step 3: Fix.** Lower each sign so it clears the sightline and stays above its door: no overlap between the sign box and the door box. Shorten the door if needed. Keep sign text, size, the door's bottom edge and the footprint. Do not move the roof or the walls.
