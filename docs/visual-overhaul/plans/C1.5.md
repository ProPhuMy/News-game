# C1.5 — Bot reliability and name-filter interface: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Morning Ledger (Gazette) publishes once in every normal round. The existing headline word filter is documented and exported as the policy that Codex enforces on player and newspaper names in D2.

**Architecture:** This is a one-branch fix in `src/bots/personalities.ts` that closes the Gazette's no-evidence gap, plus regressions in `tests/bots/`. The name filter needs no new matcher. The policy is `createWordFilter(content.wordList)` (in `src/ai/text.ts`, owned by Codex), which the server already uses for headlines. C1.5 adds accepted and rejected example data next to the word list, a test that pins the policy to those examples, and a policy note for Codex.

**Tech Stack:** TypeScript (strict), Vitest, zod schemas from `src/shared/`.

**Spec:** `docs/superpowers/specs/2026-10-14-visual-overhaul-design.md` §10 and §13 (C1.5 row). Gameplay: `docs/superpowers/specs/2026-10-09-news-town-design.md` §8.

**Branch:** `claude/c1-5-bots-filter` from `main` `72ffd6d`. The dependency is C1, which PASSED and was merged at `97093db` and `71cabff` (see `handoffs/C1.md` §12).

## Diagnosis (done before this plan)

- **Reproduction:** seeds 1–200, four engine bots, AI disabled (the engine never calls the AI). The scratch script is `repro.ts` in the session scratchpad.
  - 233 of 4,000 seat-rounds have no headline. Every one of them is a Gazette seat in rounds 2–5. The Tabloid and the Wildcard never skip.
- **Classification of the skipped rounds:** every skipped round had `card=false proofs=0 tip=true`.
  - The Gazette used its 50% "probe the lowest-trust rival" investigation (spec §8).
  - The probe found no proof, so the Gazette held no evidence card.
  - `decideWrite('gazette')` then returns `skip` unless the 10% lie roll fires.
- **Boundary:** bot scheduling (`runBotTurns`), template text (`botText`), validation (`lockHeadline`) and reveal all work.
  - The skip is a deliberate decision in `src/bots/personalities.ts:72`, added in `cf27b5d` ("Gazette never prints a blind guess").
  - Gameplay spec §8 lists no Gazette action for the case "probed a rival, no proof".
  - AI failure is not the cause: `writeBotHeadline` falls back to the engine template, and reveal uses `fallbackRating`.
- **The Caretaker is not affected:** since `cf27b5d` it always checks its tip, so it always holds a card.
- **User decision (2026-10-19):** in this case the Gazette prints a **tip story**.
  - It prints its tip's claim at the tip location, without evidence.
  - The 10% lie roll prints `hottestClaim(tip.claim)` at that location instead, which mirrors the card branch.

## Global Constraints

- `src/shared/` is frozen. No edits. `FILTERED`, `DisplayNameSchema` (20 chars) and `PaperNameSchema` (24 chars) already exist.
- Engine and bots stay pure: no `Math.random`, no `Date.now`. Randomness comes from the seeded `rng` that is passed in.
- No tuning numbers are copied. Use `TUNING.bots.gazetteLie`, `TUNING.rounds` and `TUNING.seats`.
- Claude may not edit `src/ai/`, `src/server/`, `tests/server/` or `tests/ai/`. Name enforcement at create and join is Codex D2.
- Names are never silently changed. There is no client-only filter.
- No new dependencies.
