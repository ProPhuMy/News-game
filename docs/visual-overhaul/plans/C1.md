# C1 — UI Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: revised plan for user review (2026-10-19). No product code is written until the user gives the command.

**Goal:** Give News Town a styled, readable, accessible interface (panels, states, reader labels, one results card) and prove it with inspected desktop and phone screenshots.

**Architecture:** Colors come from one palette module that sets `--nt-*` CSS variables. Plain CSS files are split by area and keyed to the existing class names. The shared capture command gains a fixture-driven UI scene, so every in-match screen can be captured over the real town with the virtual clock. Opt-in flags add palette previews, maximum-length text, keyboard focus and scrolled views.

**Tech Stack:** React 18 + TypeScript strict, plain CSS, Vite, Vitest (+ jsdom / Testing Library), `playwright-core` 1.63.0 (already installed in C0). No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-14-visual-overhaul-design.md` §3, §7, §8 (fonts), §9, §13 (C1 row). Interface: `docs/visual-overhaul/presentation-interface.md` §1, §5, §5a. Input: `docs/visual-overhaul/css-diagnosis.md`, `docs/visual-overhaul/handoffs/C0.md`. Rules: `AGENTS.md`.

**Branch:** `claude/c1-ui-baseline` (worktree `.worktrees/claude-c1`), rebased onto `main` `7457fd0`.

## Global Constraints

- Only Claude-owned paths change (AGENTS.md table). No change in `src/shared/`, `src/client/net/`, `src/client/town/`, `src/server/`, `src/engine/`, `ASSETS.md`, or fixture files.
- User text (names, headlines, bubbles) renders as text only. No `innerHTML`, no `dangerouslySetInnerHTML`.
- The UI never computes scores, readers or trust. It shows the values the server sends.
- Timers show the server deadline through the existing `CountdownTimer`. No new phase clock.
- Themed colors live only in `src/client/visuals/palette.ts`. CSS files contain no hex, `rgb(`, or `hsl(` literals.
- Shared paper-color ids stay `COLORS = ['red','blue','green','gold']` from `src/shared/ids.ts`. Paper identity always shows icon and name with the color, never color alone.
- Palette variants `a`/`b`/`c` are previews only. The final palette is chosen in D1's integrated art sample, not from C1 UI screenshots. Variant `a` keeps today's paper hexes (`#c0392b`, `#2980b9`, `#27ae60`, `#d4ac0d`, unsubscribed `#7f8c8d`), so UI and town agree until D1/D2.
- Heading font: Playfair Display (SIL OFL), self-hosted under `public/fonts/playfair-display/` with `OFL.txt` beside it. Body: system sans stack. No font CDN request.
- Keep every `pointer-events` rule in `globals.css`. The town receives drags outside panels.
- Respect reduced motion (existing `.reduced-motion` class and media query) and keep the no-WebGL fallback.
- Dev harness files stay out of `vite build` (checked after build).
- `--stress-text` is opt-in and exists only in the capture command and the harness.
- Test count: `main` `7457fd0` has 425 tests (observed baseline, not a target). Record the actual count and explain any failure.
- Files stay under about 300 lines.

## Review Focus

1. **Results card on a phone (390×844) with stress text:** every section and the Play Again button stay reachable by scroll or are always visible. Nothing is clipped without a scroll path, and the page has no horizontal scroll. Pinned by the layout check in Task 2 and the shots in Task 8.
2. **Unbroken 24-character paper names and 100-character headlines** in the standings, scoreboard, front pages and archive wrap inside their panel and never push controls off-screen. Pinned by `--stress-text` shots in Task 8 and the layout check.
3. **Keyboard-only use:** Tab reaches every control in DOM order, and the focus ring is visible on cream panels and on paper-colored buttons. Pinned by the contrast test in Task 1 and the `--tab` shots in Task 8.
4. **Heading font missing or slow:** text stays readable in the fallback serif with no invisible-text period. Pinned by the `font-display: swap` test in Task 1 and the blocked-font shot in Task 8.
5. **Standings on a phone during play:** the strip does not cover the action panel or the timer. Pinned by the investigate and write shots at 390×844 in Task 8.

## Calls made in this plan (user can override)

- The font ships as the upstream variable TTF, because no woff2 converter is installed and adding one would be a new tool.
- `paletteCssVariables` is added beside the interface §1 exports, so the capture command can apply palettes in Node without a DOM.
- `--block-fonts`, `--tab` and `--scroll` are capture-only flags used to prove the fallback, focus and scroll requirements in real renders.
- The layout check fails a capture on horizontal page overflow or an unreachable control. This turns the "no trapped content" rule into a measured check.
