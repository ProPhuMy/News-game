## Review focus

1. Wrong or stale deploy: assets must match the exact local candidate build; host metadata must identify that SHA, not merely a reachable page.
2. Remote target mistakes: require explicit HTTPS origin, reject credentials/query/path and unintended redirects; preserve local-only default.
3. Recovery across real WSS: separate seats remain separate, guest token restores its own seat and known locked action, and host stays connected in the same process.
4. Apparently loaded assets: verify bytes/MIME and browser font/render readiness; inspect actual production results and town rather than accepting only HTTP 200.
5. AI/host failure confusion: test controlled provider failure separately; process replacement must report lost in-memory rooms rather than claim durable reconnect.
